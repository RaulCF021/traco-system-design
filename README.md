# Traço

Laboratório interativo de System Design em português. A trilha reúne seis aulas, missões com critérios mensuráveis, um tutorial de montagem e experimentos A/B sobre cache, filas e balanceamento.

## Executar

Com Node.js 22 ou superior instalado, rode `npm start` na raiz do projeto e abra <http://127.0.0.1:5187>. No Windows também é possível usar `Iniciar.cmd`. O projeto serve módulos JavaScript diretamente, sem instalação de dependências. Para usar outro servidor estático, sirva a pasta `dist`.

## Estudar

O percurso começa com um pedido explicado em três passos, seguido de análise de requisitos, montagem orientada, laboratório aberto e revisão de arquitetura. Cada um dos quatro projetos oferece esse percurso. O levantamento escrito pelo aluno fica disponível no laboratório. O catálogo pesquisável de componentes tem critérios de escolha, alternativas e experimentos. A revisão avançada inclui mudança de requisito, cálculo de carga e registro da decisão.

Escolha entre loja online, agenda, geração de documentos e entrega de mapas. Cada projeto combina perguntas de arquitetura, um desenho editável e experimentos com carga, custo e dependências. No guia de componentes, cada peça tem uma explicação e um ensaio editável. **Meus projetos** abre uma tela em branco para modelar outro problema e guardar seu próprio desenho. Os estudos de caso e os tutoriais ficam disponíveis separadamente.

O simulador estima demanda, vazão, latência média, crescimento de fila e custo relativo. Capacidades e taxas de acerto são hipóteses didáticas. As aulas de Netflix e Spotify incluem referências técnicas das empresas.

## Verificar o motor

Execute `npm test`. Os testes cobrem dependências, cache, gargalos, balanceamento, falhas e filas.

A fonte Fraunces acompanha a distribuição sob a licença em `dist/fonts/fraunces-license.txt`.
